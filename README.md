# Wanderlust – Travel & Destination Booking Platform

Wanderlust is a travel platform that allows users to explore destinations, discover travel opportunities, and manage their bookings through an intuitive and user-friendly interface.

## Technologies Used

- Next.js
- React.js
- JavaScript / TypeScript
- Tailwind CSS
- Node.js (API integration)
- Express.js (Backend API)
- MongoDB (Backend database)

## Key Features

- **Explore Destinations:** Browse available travel destinations and discover new places.
- **Destination Details:** View detailed information about individual destinations.
- **User Authentication:** Secure user authentication and protected pages.
- **Booking Management:** View and manage personal bookings through a dedicated page.
- **Responsive Design:** User-friendly interface across different screen sizes.
- **API Integration:** Fetch and display destination and booking data from the backend API.

## Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/mahfuz-subed/wanderlust-client
```

### 2. Navigate to the Project Directory

```bash
cd wanderlust-client
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the root directory and add:

```env
NEXT_PUBLIC_API_URL=http://localhost:5000
```

Make sure your backend server is running on the configured API URL.

### 5. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
